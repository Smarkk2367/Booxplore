# Booxplore
Booxplore is an android app, built using Kotlin and Jetpack Compose that allows the user to browse various titles via a simple, intuitive UI.

## Features:

* **Search** every book you need by it's title or author!
* **Add** your books to favorites and don't let yourself forget about them!
* **View** each and every detail about any chosen title!
* **Personalize** your experience, with 3 distinct color themes, dark mode and light mode!

## Tech:
* **Language:** kotlin
* **UI Framework:** jetpack compose
* **Nagivation:** navigation compose
* **Network:** retrofit & okhttp
* **Serialization:** kotlinx serialization
* **Image loading:** coil
* **Local storage:** sharedpreferences
* **API: OpenLibrary API**

## Getting Started:
* **1. Clone the repository:** ```git clone https://github.com/Smarkk2367/Booxplore.git```
* **2. Launch in Android Studio**
* **3. Wait for GradleSync to complete -> Select an emulator or connected device -> Run the app!**
